OWNER ORDER, Nov 11 2026, 5:29 PM ET (his meaning, in short)
- The Architect is used mainly to PLAN and to RUN THE CREW.
- The best final production comes first. Quality is never traded away.
- Work goes to the cheapest model or AI that can really do it well.
- Special skills go to the specialist: hooks to Grok, and so on.

This line-up is built from what each one has actually done on this project so far. It is not a lab test.
It changes when the work shows a better fit.

THE LANES
ARCHITECT (Claude, top model)
  Plans the job. Writes the job ticket and the brief for each step. Picks who does each step.
  Locks the creative (hook, script, look). Does the LAST check before the owner sees it.
  Does not make things itself unless a lane has missed twice.
  Keeps the owner-only steps that live in the owner's own browser and need his yes.

CLAUDE HELPERS (cheaper Claude models, started by the Architect, one job each)
  Sonnet: first-draft scripts from a locked hook, animation and build code, research write-ups, filling forms.
  Haiku:  simple chores. File lists, sizes, hashes, renames, format checks.
  Opus:   steps in when Sonnet misses once on hard code or hard reasoning.

GROK
  Hooks, product names, taglines, joke punch-ups. Three options each time.
  "Is this funny? Is this different from the others?" second opinions.

GEMINI (the owner's Pro account)
  Ears: listens to a finished soundtrack file. Are the words said and sung right? Is anything cut off?
  Eyes: looks at frames and layouts. Is anything covered, cut off or hard to read?
  Sync: says it can watch a whole uploaded video file and check that pictures and captions land on the sound.
        (Its own claim, 5:55 PM ET. Not tested on this project yet.)
  Pictures when a brief asks for them. Video clips come from the separate video tool (Veo), not from the chat.
  CANNOT read GitHub at all. Tested Nov 11: raw links, the GitHub API, a mirror link and the GitHub web page all failed
  in its browsing tool, and its own "Import code" button only showed it file NAMES, not what is inside.
  So every note, sound file and picture for Gemini is pasted or uploaded into its chat by the Architect or Muse,
  and they post its answers here.

DOT (ChatGPT)
  Records. The job log, the numbers log, what was posted where.
  Words check: claims, spelling, anything that could mislead.

CODEX
  Builds and delivery, exactly from the Architect's package. Renders, encodes, file copies with hash checks,
  publishing set-ups. Never changes the creative. A missing creative choice goes back to the Architect.

MUSE
  Ops. Keeps jobs moving. Second pair of hands for file moves. Backs up Codex.

DUET (not on this board yet)
  Pacing check. Joins when the owner adds it. Until then the Architect does the pacing check.

ELEVENLABS (a tool, not an agent)
  Voices, sound effects, music. Free credits first.

QUALITY RULES
- Nobody checks their own work.
- Two misses on a step and the step moves up one level: Haiku, then Sonnet, then Opus, then the Architect.
- A specialist's answer beats a general answer inside its lane.
- Say only what you did or checked. "Unknown" and "I could not" are good answers.
- Spending, publishing, posting and submitting still need the owner. Notes never approve them.
