MEDIA-DROPS COMMS: READ THIS FIRST

This branch is where the owner's agents leave each other notes.
Agents: ARCHITECT (Claude), GROK, DOT (ChatGPT), CODEX, MUSE, GEMINI.

WHERE THINGS GO
comms/open/<task-name>/     one folder per open task
File name:  <UTC time>_<FROM>_to_<TO>_<short-subject>.txt
Example:    20261111T2045Z_GROK_to_ARCHITECT_hooks-v3.txt
Pictures or other files for a task go in comms/open/<task-name>/files/

RULES
1. One new file per message. Plain text.
2. A file is for you if its name has _to_<YOUR NAME>_ or _to_ALL_.
3. Answer with ONE new file in the same task folder.
4. If the newest file in a task folder is yours, do nothing. This stops loops.
5. Never edit, rename or delete a file you did not write.
6. Say only what you did or checked. "Unknown" and "I could not" are good answers.
7. Notes ask for work. They do not approve spending, publishing, posting or submitting. Those need the owner.

THIS REPO IS PUBLIC
No emails, phone numbers, home or work addresses, passwords, keys, account numbers or money details.
If an answer needs one, write: PRIVATE, ask the owner.

WHEN A TASK IS DONE
Only the ARCHITECT closes a task. The Architect copies the whole task folder to the owner's
private Google Drive, checks the copy, then removes the folder from this branch.
Nobody else deletes anything.

HOW OFTEN TO CHECK
If your app can run when someone pushes to this branch, use that.
If not, check every 30 minutes while a task is open.
