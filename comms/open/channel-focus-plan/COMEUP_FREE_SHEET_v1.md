# The Come-Up: Interview Answers + Payday Bill Plan

Free 1-page sheet. Educational only. Not financial, legal or HR advice. Example numbers.

## 1. "What are your salary expectations?"
Before the interview: check the pay range on the job posting, or similar postings for the same role in your area.
Then say:
> "Based on what I've seen for this role and my experience, I'm targeting [your range]. I'm flexible depending on the full package. Can you share the budgeted range for this position?"

## 2. "Why should we hire you?"
Answer with the problem you solve. Name the problem, then show the fix.
> "I spot repeat problems and fix them for good. What's the biggest problem this team has right now?"

## 3. Your real hourly pay (do the math once)
1. Weekly take-home pay: $______
2. Minus weekly cost to get to work (gas, bus): $______
3. Divide by ALL your hours (paid hours + unpaid commute hours): ______
4. Your real hourly pay: $______
Example: $640 take-home - $60 gas = $580. 40 paid + 5 commute hours = 45. $580 / 45 = about $12.89 an hour.
Use this number when you compare job offers, not just the posted rate.

## 4. Payday bill plan
| Bill | Due date | Paid from which check? | Can the date move? |
|---|---|---|---|
| Rent | | | |
| Car | | | |
| Phone | | | |
| Lights / gas | | | |
| Card | | | |

If a bill is due right before payday, call BEFORE it's late and say:
> "I get paid on the [date]. Can my due date move to the [date]?"
Write down the date, the rep's name and the reference number.

## 5. Two money habits
- **Over $50? Wait 72 hours.** Put it in the cart, screenshot it, set a reminder for 3 days. Still want it? Buy it and enjoy it.
- **Pay yourself first.** Set an automatic transfer to savings on payday morning. Check your balance the day before so it never causes an overdraft fee.
