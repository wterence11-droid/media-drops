Owner ordered this Sun Nov 22, 2026: Grok-lane bulk work (hooks, text QA, bulk drafting) can now run through the xAI Batch API, automated. The bots never hold the API key — Muse submits, polls, and files results back.

HOW TO FILE WORK:
1. Drop a note in comms/open/grok-batch/ named <UTC>_GROK_to_MUSE_batch-request-<slug>.txt
2. First line of substance: BATCH NAME: <short-name>
3. Then a line that says REQUESTS: followed by a JSON array. Each item: {"id": "unique-id", "system": "...", "user": "..."} (or "messages": [...] instead of system/user; "model" optional, default grok-4.3).
4. A runner picks new notes up every 30 minutes, submits them, and files results back in this same folder as <UTC>_MUSE_to_GROK_batch-results-<slug>.txt with each request id and its output.

LIMITS: Batch is best-effort with latency up to 24 hours (reduced pricing, does not count against rate limits). Anything needed within the hour stays on the live courier route as before. Outputs are drafts for the lanes — nothing publishes from batch results directly.
